### 3. 차례 시작·넘기기를 `GameRoom` 한 곳에

- AI 응답: `startTurn(닉네임)` = `TURN` + 문제 시간 멈춤 + 답변 시간 시작. `passTurn(닉네임, 판정)` = 감점 → `next()` → `SYSTEM`·`RESULT`·`SCORE`·`QUEUE` → 다음 사람이 있으면 `startTurn`, 없으면 `TURN|` + 문제 시간 재개. 오답(`answer()`)과 시간 초과(`answerTimeUp()`)가 같은 `passTurn`을 씀
- 판단: 채택. 오답과 시간 초과는 판정 글자만 다르고 하는 일이 같아서 한 메서드로 묶음. `RESULT`를 `QUEUE`보다 먼저 보내는 순서를 지킴 — 화면이 `RESULT`로 「다시 못 울려요」를 띄우고 뒤에 오는 줄에 내가 없어도 그 안내를 남기기 때문
- 수정: 채팅 알림은 UI 명세서 M8처럼 다음 사람이 있으면 「주성 님 오답! -1점 · 이건 님 차례예요」로 붙임

### 4. 늦게 온 시간 초과 막기

- AI 응답: 타이머는 시간이 다 된 순간 잠금 밖에서 부르므로, 그사이 답이 와서 차례가 넘어갔거나 라운드가 끝났을 수 있음. `answerTimeUp(닉네임, 문제 번호)`가 잠근 뒤 「같은 문제인지, 그 사람이 아직 차례인지」를 다시 확인
- 판단: 채택. 확인이 없으면 정답을 보낸 바로 그 순간 10초가 끝날 때 끝난 차례에 감점이 한 번 더 들어감. 문제 타이머의 `finishRound()`가 `roundActive`로 한 번만 실행되게 막는 것과 같은 생각

### 5. 화면: 벨 회색·답변 카운트다운

- AI 응답: `BellPanel`이 `RESULT`를 받아 내가 틀렸으면(정답이 아니면) 벨을 끄고 「이 문제는 다시 못 울려요」(UI 명세서 M11). 다음 `QUESTION`에서 원래대로 켜짐. `AnswerPanel`은 내 `TURN`이면 수업 `ShootingGame`처럼 `javax.swing.Timer`로 「내 차례! 시간 안에 답하세요 (10초)」를 줄이고, 입력을 끌 때(답 보냄·판정·정답 공개·남의 차례) 같이 멈춤

- 수정 1: 빈 차례(`TURN|`)가 오면 원래 코드는 판정 안내를 지웠음 → 이제 줄이 빌 때마다 `RESULT` 바로 뒤에 `TURN|`이 와서 「주성 님 오답!」이 바로 사라짐. 빈 차례에서는 판정 안내를 남기도록 고침. 다음 사람 차례(`TURN|이건`)일 때만 지움(채팅에 「이건 님 차례예요」가 남음)

### 이해한 내용

- 문제 시간과 답변 시간은 따로 잰다. 그래서 문제 시간이 1초 남았을 때 벨을 울려도 답변 시간은 10초를 다 쓴다. 답하는 동안 문제 시간은 멈춰 있다가 줄이 비면 남은 1초부터 다시 흐른다.
- 재도전 금지는 `BellQueue.next()`가 틀린 사람을 기록하는 것만으로 서버 쪽이 끝난다. `buzz()`는 이미 `add()`가 `false`면 무시한다(#14).
- 테스트에서 10초를 기다리지 않으려고 `QuestionTimer`를 상속한 기록용 타이머를 넣었다. 부모 메서드를 안 불러서 타이머 스레드가 생기지 않고, `timeUp()`으로 「시간이 다 됨」을 흉내 낸다.
